AHORCADO V20 - AUDITORÍA Y CURADO DE LA BASE DE PALABRAS
=============================================================

RESUMEN
-------
Corpus final: 548 respuestas únicas.

- Países: 195
- Ciudades: 150
- Marcas de autos: 62
- Bandas de Rock: 141

CRITERIOS APLICADOS
-------------------
1. Ortografía real de cada nombre, conservando tildes, diéresis y otros
   caracteres cuando corresponde.
2. Sin duplicados dentro de una misma categoría.
3. Nombres comunes y reconocibles; se evitaron denominaciones oficiales
   innecesariamente extensas cuando una forma común resulta más jugable.
4. En Ciudades, Marcas y Bandas se priorizó reconocimiento por encima de
   exhaustividad.
5. Países contiene el conjunto completo de 195 estados usado para el juego.
   Algunos microestados y países menos conocidos se conservan porque forman
   parte natural de esa categoría.
6. Las respuestas largas se verificaron contra el área visual del juego.

CORRECCIONES DE DATOS HISTÓRICOS
--------------------------------
- EL SAVADOR -> EL SALVADOR
- PANAMA -> PANAMÁ
- PERU -> PERÚ
- EMIRATOS ÁRABES -> EMIRATOS ÁRABES UNIDOS
- PARIS -> PARÍS
- SAN PABLO -> SÃO PAULO
- MERCEDES BENZ -> MERCEDES-BENZ
- Se eliminan duplicados como las múltiples entradas de NUEVA YORK.

INTEGRIDAD
----------
Se agregó un índice UNIQUE sobre categoría + palabra (sin distinguir
mayúsculas/minúsculas ASCII) para impedir duplicados exactos futuros.

Las bases locales de versiones anteriores se migran a versión 4 sin borrar
palabras personalizadas por el usuario. Sólo se corrigen nombres históricos
conocidos y se eliminan duplicados exactos.

PALABRAS LARGAS Y DISEÑO
------------------------
Se mantuvo el objetivo de no superar dos líneas en el tablero.

Frases que activan automáticamente un modo compacto global:
Países:
- EMIRATOS ÁRABES UNIDOS
- SAN CRISTÓBAL Y NIEVES
- SAN VICENTE Y LAS GRANADINAS

Bandas:
- ELECTRIC LIGHT ORCHESTRA
- STONE TEMPLE PILOTS
- RED HOT CHILI PEPPERS
- THE SMASHING PUMPKINS
- RAGE AGAINST THE MACHINE
- LOS FABULOSOS CADILLACS

Tokens excepcionalmente largos que usan el modo muy compacto:
- CENTROAFRICANA (en REPÚBLICA CENTROAFRICANA)
- ATERCIOPELADOS

La reducción se aplica sólo a esas respuestas problemáticas. Las palabras
normales mantienen el tamaño de celda habitual.

DIFICULTAD
----------
No se agregó una columna de dificultad porque la versión actual no la usa
para seleccionar palabras. En cambio se hizo un curado manual y mecánico.

Casos deliberadamente conservados como "difíciles pero válidos":
Países:
- ESUATINI, KIRIBATI, NAURU, PALAOS, TUVALU, YIBUTI, COMORAS, BRUNÉI,
  LESOTO, VANUATU.
  Se conservan porque son países soberanos, aunque sean menos conocidos.

Ciudades:
- TEGUCIGALPA, REIKIAVIK, JOHANNESBURGO, ADDIS ABEBA, KUALA LUMPUR,
  HO CHI MINH, KATMANDÚ.
  Son nombres reconocibles y justos para una categoría de ciudades.

Marcas:
- ABARTH, DACIA, DAIHATSU, GENESIS, INFINITI, ISUZU, POLESTAR, ŠKODA.
  Son marcas reales con reconocimiento suficiente para el corpus.

Bandas:
- LYNYRD SKYNYRD, ATERCIOPELADOS, BERSUIT VERGARABAT, LEGIÃO URBANA,
  TITÃS, DUNCAN DHU.
  Son nombres establecidos, aunque su ortografía aumenta la dificultad.

RESPUESTAS COMPLETAS
--------------------
Al usar "Arriesgar", la comparación ahora ignora:
- mayúsculas/minúsculas;
- tildes y diéresis;
- espacios;
- guiones, apóstrofes, puntos y barras.

Los números sí se conservan.

Ejemplos aceptados:
- ACDC = AC/DC
- REM = R.E.M.
- MERCEDES BENZ = MERCEDES-BENZ
- EMIRATOS ARABES UNIDOS = EMIRATOS ÁRABES UNIDOS

La presentación siempre conserva la escritura correcta almacenada.
