INSTALACIÓN

Descargá y jugá.

Los instaladores incluyen su propio runtime. No necesitás instalar Java por separado.

⊞

Windows

64 bits · x86-64

  1. Descargá Ahorcado-1.1.0.exe.
  2. Hacé doble clic y seguí los pasos del instalador.
  3. Abrí Ahorcado desde Inicio o desde el acceso directo.
SmartScreen

Al no utilizar todavía un certificado comercial de firma, Windows puede mostrar una advertencia. Desde este repositorio oficial, elegí Más información → Ejecutar de todas formas.

◆

Linux

Debian / Ubuntu / Mint · x86-64

  1. Descargá ahorcado_1.1.0-1_amd64.deb.
  2. Abrilo con el instalador de software de tu distribución.
  3. Ahorcado aparecerá en el menú de aplicaciones.
O desde Terminal: sudo apt install ./ahorcado_1.1.0-1_amd64.deb
